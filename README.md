# QuilrAI Solution Architect Assessment

Solutions for the four-part QuilrAI Solution Architect take-home. Each task lives in its own folder with its own README.

| Task | Description |
|---|---|
| 1 | [Customer-service MCP server over stdio](task1-mcp-server/) |
| 2 | [MCP security gateway with authentication and tool-level authorization](task2-mcp-gateway/) |
| 3 | [Streaming LLM gateway that redacts PII in real time](task3-llm-gateway/) |
| 4 | [LLM router with a token rate limiter and model failover](task4-llm-router/) |

Prerequisites: Python 3.12 and [uv](https://docs.astral.sh/uv/). Each task folder is self-contained; run `uv sync` inside it.
